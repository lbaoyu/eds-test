Core Principle

One home folder per asset; search and tags do the finding

The most common mistake in a new DAM is recreating an 8-level shared drive where teams click through folders to hunt for files. In AEM Assets, folders are the foundation of the house—they automate who has access and what rules apply on upload—while Search, Filters, and Collections let users find assets in seconds.

Create a Folder · Governance

Split into a new folder only when these differ

Folder Job
  • Team Access RightsDifferent groups need permission to view, upload, edit, or approve files.
  • Metadata Forms & Default TagsProduct photos need SKU fields; campaign folders auto-tag the Campaign Name and Year.
  • Automatic Image Crop RatiosProduct packshots need 1:1 & 4:5 crops; campaign heroes need 16:9 & 9:16.
  • Auto-Approval vs. Review GateOfficial brand logos can auto-approve on upload; campaign & Express outputs wait for review.
  • Content Lifecycle StageKeep unfinished studio shoots (WIP) and retired archives out of everyday libraries.
Use Tags & Collections · Discovery

Never create separate folders for these

Metadata Job
  • File Format or OrientationAEM Search and Adobe Express let users filter by JPG, PNG, PDF, SVG, or landscape/portrait in one click.
  • Marketing Channels (Web, Email, Social)Tag intended channels in metadata and let Dynamic Media resize the single approved master.
  • Seasonal Kits & Agency PacksGroup assets from multiple folders into a shareable Collection (like a playlist) without copying files.
  • Launch Dates & Usage ExpirationSet scheduled go-live/end dates and license expiry on the asset—delivery stops automatically when expired.
  • Topic, Mood & Campaign BriefsAI Search in AEM and Adobe Express understands synonyms, multiple languages, and uploaded brief documents.

Rule 013–5 Levels

Keep folders shallow

Short paths make it obvious where contributors should upload files and keep folder breadcrumbs readable inside Adobe Express.

Rule 02≤1,000 Files

Split large branches early

Break high-volume areas by Year (2026/) or Product Line so no single folder becomes a 10,000-file dumping ground.

Rule 03Leaf Folders Only

Store files in the lowest folder

Upper folders should hold subfolders only. Mixing loose files alongside subfolders slows folder-tree loading and causes confusion.

Rule 04Uncheck “Orderable”

Use standard auto-sorted folders

When creating folders, leave Orderable unchecked—checking it slows large folders and disables AEM Folder Sharing.

Rule 05Global → Local

Put region at the bottom

Avoid top-level /apac or /emea silos; nest market folders under the shared campaign so teams see and reuse global masters.

Rule 06Deactivate First

Unapprove before moving

Remove Approved status (and unpublish if live) before moving or archiving folders. Reprocess files moved into auto-approved folders.

Naming Standards

Clear folder titles, clean URL names, and self-describing files

Every AEM folder has both a Display Title for people and a Folder Name used in web links. Agreeing on simple naming rules up front prevents broken links, blocked uploads, and confusing search results.

1 · Folder Display Title (Easy to Read & Change)
Autumn Rewards — APAC (2026)

Shown on folder cards and breadcrumbs. Use normal title case and spaces, stick to plural nouns for categories (Campaigns, Products, Logos), and skip redundant words like “Folder”. Editing the Display Title later never breaks links.

2 · Folder URL Name (Lowercase & Permanent)
autumn-rewards-apac-2026

Used in the folder’s address. Use lowercase letters, numbers, and hyphens only (AEM turns spaces into - automatically when you create a folder). Use YYYY or YYYY-MM dates so folders sort in calendar order.

Characters blocked in Folder Names (stricter) * / : [ \ ] | # % { } ? & " . ^ ; + AEM blocks dots (.), quotes, pluses, and tabs in folder names—stick to letters, numbers, and hyphens.
Characters blocked in File Names * / : [ \ ] | # % { } ? & ;= Also avoid spaces and accents in filenames so web delivery links stay clean and readable.
Recommended File Naming Pattern (Aim for 50–75 Characters) Keep under 100 chars (longer names auto-shorten in Dynamic Media)
[brand]meridian - [campaign-or-line]autumn26 - [subject]platinum-couple - [ratio-or-use]hero-16x9 - [market]en-sg . [ext]jpg
Example (52 chars): meridian-autumn26-platinum-couple-hero-16x9-en-sg.jpg Revisions: Upload edits as a New Version of the same file—never _FINAL_v2.jpg.

Dynamic Media (OpenAPI)

Folder decisions for image delivery

  1. 1
    Separate auto-approved kits from review-gated folders Only Approved assets (latest version) are delivered downstream. Auto-approve trusted folders like /brand-foundation via folder profile, while keeping /wip-studio and express-adaptations/ unapproved until reviewed.
  2. 2
    Align folders with Smart Crop aspect ratios (~5 per folder) Keep /products (square 1:1, portrait 4:5) separate from /campaigns (widescreen 16:9, vertical 9:16) so each folder gets a lean, relevant Image Profile (assigned by Admins under Tools › Assets › Image Profiles; note: Smart Crop requires Dynamic Media Ultimate).
Adobe Express

Folder decisions for self-service teams

  1. 1
    Connect Express to the “Author” repository Always select the Author repository inside Express Content Advisor so users see your folders, Collections, and Saved Searches (selecting a Delivery repository flattens everything into a single unorganized list).
  2. 2
    Give Express users dedicated express-adaptations/ folders Keep master folders read-only. Note three save-back behaviors: exporting All Pages as PNG/JPG creates a new subfolder automatically; JPG/PNG edits can save as a new version (PDFs save as new files); and if using Content Hub, turn off Auto-approval.

Roles & Permissions

Set rules at the top and let subfolders inherit them

Always grant access to Role Groups (never individual people) so staff changes never require folder updates, and grant permissions top-down rather than adding complex “Deny” exceptions deep inside subfolders.

Pitfalls & Checklist

Five folder traps to avoid — and your pre-launch checklist

Catching these five habits before migrating files saves months of manual cleanup later.

Trap 01 · Naming Folders After Teams /marketing-dept-team-b/

Teams reorganize every 1–2 years, turning team-named folders into outdated mazes.

→
Better Approach /products/ · /campaigns/2026/

Organize around stable business topics (products, campaigns, brand) that survive reorgs.

Trap 02 · Top-Level File-Type Folders /images/ · /videos/ · /pdfs/

Scatters one campaign across three separate trees and triples folder administration.

→
Better Approach Keep campaign assets together

Store all formats for a campaign in one branch and use Search’s built-in File Type filter.

Trap 03 · Duplicating Files Per Channel /web/hero.jpg + /social/hero.jpg

Wastes storage and creates a compliance risk when an expired image is updated in only one place.

→
Better Approach One approved master + Dynamic Media crops

Deliver every channel size from one file and curate seasonal bundles with Collections.

Trap 04 · Letting Everyone Create Top Folders /Johns_Test/ · /New Folder (2)/

Results in hundreds of ad-hoc folders with no default metadata, approval gates, or Smart Crops.

→
Better Approach Lock Levels 1–2 to DAM Admins

Allow contributors to add subfolders only inside /campaigns/2026/ and /wip-studio/.

Trap 05 · Dumping Legacy Drives As-Is 12,000 old files in /legacy-import/

Slows folder browsing and exposes unreviewed or expired files if bulk-approved by mistake.

→
Better Approach Curate in batches (≤1,000/folder) + CSV tags

Migrate only active, rights-cleared assets into partitioned folders and apply metadata in bulk via CSV.
