Read the pattern

Move from roll-up to evidence

Start with the overall direction, then segment by market-language, platform, category, prompt, and time. Inspect prompt-level responses, mentions, citations, topic context, and competitor patterns before deciding what to change.

Keep comparisons useful

Use a consistent scope

For a fair trend, keep tracked prompts, market-language, platform selection, and time windows comparable. Expanded coverage can improve representation — but it changes what the dashboard measures.

Mentions and citations are response-based: they count responses containing one, not every repeated occurrence.

Measurement toolkit

Curate prompts before the baseline

Recommended sequence for an evolving strategy.

01

Define

Objective, product/topic, market, and target content.

02

Review

Candidate prompts; Semrush Suggestions as discovery input.

03

Add

Selected prompts to the Prompt Library; allow up to 24h.

04

Record

Finalize the core cohort and its version.

05

Baseline

Create the Workspace strategy and capture baseline before work starts.

06

Hold

Keep the cohort stable; new prompts = a new cohort version.

Prompt Strategy ≠ Opportunity Workspace Strategy. The first discovers prompts; the second is the initiative-level record that groups related opportunities around one goal.
Boundary: Semrush recommendation or market metrics are not ABV strategy outcomes. Keep them out of the scorecard and readout.
