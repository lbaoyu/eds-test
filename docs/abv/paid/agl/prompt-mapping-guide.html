Branded vs. non-branded

Branded vs. non-branded is automatic

Classified for every prompt

The Prompt Library shows the branded / unbranded balance and flags when the branded share drifts outside a healthy range.

Filtered in Brand Presence

Brand Presence filters by branded vs. non-branded. Adobe guidance is not to create categories for brand / non-brand or geography.

Add AGL plan and product names as brand aliases. In Brands Management › Aliases, add names such as Three for Free so mentions of them count toward AGL.

Intent & custom tags

Tags for AGL’s own reporting views

Intent is classified automatically

Each prompt gets one of five intents, and the Prompt Library tracks intent coverage.

  • Informational
  • Navigational
  • Commercial
  • Transactional
  • Task

A funnel tag separates Awareness

“How can I lower my electricity bill…” and “What is the daily supply charge…” are both Informational intent. A Funnel > Awareness tag reports the first one separately.

Suggested tag groups

TagSub-tagsExample prompt
FunnelAwareness · Informational · CommercialHow can I lower my electricity bill without being cold in winter?
StateNSW · QLD · VIC · SA · ACTWho has the cheapest electricity rates in NSW?
PlanThree for Free · other AGL plansHow does the AGL Three for Free plan work?
FeatureGreenPower · other featuresDoes AGL offer GreenPower so I can match my electricity use with renewable energy?
tags column Funnel > Commercial; State > NSW
  • Separate tags with a semicolon ;
  • Nest a sub-tag with >, as in Tag > Sub-tag
  • Tags that don’t exist yet are created on import
  • Reserved names can’t be tags: category tag intent origin type source — hence Funnel, not Intent

Next steps

From list to live tracking

  1. Build the full list

    Use the four columns above for each priority product line. Save as UTF-8 CSV.

  2. Review names before import

    Confirm subcategory names, tag names, and brand aliases with the Adobe team.

  3. Import the CSV

    Prompt Management›Prompt Library›select the AGL brand and market›Import CSV

  4. Review after processing

    New prompts take up to 24 hours to appear in Brand Presence. Then check the Branded / Unbranded and Intent coverage tiles in the Prompt Library.
