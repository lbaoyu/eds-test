Mental Model

One physical home per asset; infinite virtual views

Avoid rebuilding a 9-level shared network drive for browsing. In AEM Assets, folders exist to inherit security, metadata, and processing rules, while Omnisearch, AI Search, Collections, and OpenAPI URLs handle discovery and multi-channel delivery.

Layer A · Storage & Inheritance

Split a folder only when these 5 differ

Folder Tree
  • Access Control Lists (ACLs)Different user groups need Read, Create, Modify, or Delete rights.
  • Metadata Schemas & ProfilesAssets need distinct property forms or auto-stamped Brand/Campaign/Market values.
  • Processing & Smart Crop ProfilesEcommerce packshots (1:1, 4:5) vs. campaign heroes (16:9, 9:16).
  • OpenAPI Auto-Approval PolicyCurated brand kits auto-approved on upload vs. folders gated by manual review.
  • Lifecycle StageIsolating raw studio WIP and retired archives from active production libraries.
Layer B · Discovery & Delivery

Never create folders for these 5

Metadata & API
  • File Format & OrientationBuilt-in MIME type, extension, and dimension facets filter these automatically.
  • Delivery Channels (Web, Social, Email)Tag channels in metadata; generate channel sizes on demand via OpenAPI URL modifiers.
  • Seasonal Kits & Agency HandoffsBundle assets across folders virtually with static or Smart Search Collections.
  • Publish Windows, DRM & IMS RestrictionsOn/Off Time, Expiration Date, and IMS roles enforce access at the OpenAPI CDN edge.
  • Intent, Synonyms & Campaign BriefsContent Advisor AI Search matches multilingual queries and PDF/DOCX/TXT briefs to metadata.

Rule 013–5 Levels

Keep paths shallow

Short paths make upload locations obvious for contributors and keep breadcrumbs legible inside Adobe Express.

Rule 02≤1,000 / Leaf

Partition high-volume branches

Introduce deterministic partition folders (/2026/, /<product-line>/) before any folder crosses 1,000 assets.

Rule 03Leaf Only

No loose files in parent nodes

Upper folders hold subfolders only; mixing hundreds of binaries with child folders slows UI tree expansion and muddies inheritance.

Rule 04sling:Folder

Use unordered JCR folders

Always script sling:Folder (AEM default), never sling:OrderedFolder, which bottlenecks Oak with an ordered child-list array.

Rule 05Deactivate → Move

Clear approval before moving

Revoke Approved status (<10m OpenAPI TTL) and unpublish before moving/archiving. Reprocess unapproved files moved into bulk-approved folders.

Rule 06Locale at Leaf

Global top, market at leaf

Avoid Level-1 /apac or /emea silos unless required by data-residency law; nest market folders beneath shared campaigns.

Naming & URL Anatomy

How folder slugs and filenames map to OpenAPI URLs

Separate human display labels from machine-safe slugs, and structure filenames so they power clean SEO delivery URLs and unmistakable search cards in Adobe Express.

1 · Folder UI Title (jcr:title — Editable)
Autumn Rewards — APAC (2026)

Human-readable title case for breadcrumbs and cards. Safe to rename anytime without changing the JCR path or OpenAPI asset UID. Use consistent plural nouns (Campaigns, Products) and drop redundant words like “Folder”.

2 · JCR Node Slug (Path Name — Immutable)
autumn-rewards-apac-2026

Lowercase ASCII letters, digits, and hyphens only (spaces in titles auto-convert to - on creation). Use sortable ISO prefixes (2026-09) and locale codes (en-sg, zh-hk).

Disallowed AEM filename characters: * / : [ \ ] | # % { } ? & Also avoid spaces, accents, and punctuation (! @ $ ^ + = ~ ,) to prevent URL percent-encoding.
Asset Filename Formula (50–75 chars) → OpenAPI Endpoint Upload edits as AEM Versions · Updates live URL in <10m

Dynamic Media with OpenAPI

4 configuration mechanics tied to folders

  1. 1
    Approval Target & bulk-approval Metadata Profiles Delivery exposes approved assets to both OpenAPI and Content Hub; Content Hub scopes them to internal org users only. Rejected or Changes requested blocks delivery immediately.
  2. 2
    Field-level security on Review Status Generic folder write access does not grant approval rights—enable and restrict edit access on the Review Status field inside each folder’s Metadata Schema.
  3. 3
    Lean Smart Crop profiles (~5 ratios) & zero-config video Keep Image Profiles around ~5 focal-point ratios per folder (>5–10 slows ingestion; limit 100; N/A for PDF/GIF/INDD). OpenAPI serves adaptive HLS/DASH video dynamically up to 50 GB / 2 hrs without Video Profiles (note: DM Prime omits AVIF Smart Imaging).
  4. 4
    Edge-enforced On/Off Time, Expiry & IMS roles Scheduled jcr:content/onTime & offTime, asset expiration, and Adobe IMS user/group restrictions (Bearer token or delivery-token cookie; unauthorized returns 404) take effect in <10 minutes.
Adobe Express

4 repository & save-back rules

  1. 1
    Select the AEM Author repository (never Delivery) Only the Author repo in Express exposes folders, Collections, Saved Searches, AI Search, and brief uploads (AEM release ≥21994 + GenAI Rider). Delivery repos flatten all files to root.
  2. 2
    Preview real-time modifiers without mutating masters Designers can test OpenAPI modifiers (resize, rotate, flip, quality) live inside Content Advisor before placing onto the canvas—preview modifiers never overwrite the DAM asset.
  3. 3
    Plan for multi-page canvas subfolder creation When saving back via Share → AEM Assets, exporting All Pages as PNG/JPEG automatically creates a new child folder inside express-adaptations/ (PDF exports as a single file).
  4. 4
    Disable Content Hub Auto-approval When Embedded Express saves to Content Hub (where mandatory Project/Campaign Name metadata auto-derives hydrated folders), turn off Auto-approval so drafts don’t auto-publish within 5 minutes.

Governance Matrix

Top-down inheritance & authoritative role mapping

Anti-Patterns & Checklist

Five structural traps to refactor before migration

Validate your proposed taxonomy against these five anti-patterns before running bulk ingestion or CSV metadata imports.

Trap 01 · Org-Chart Paths /dept-mktg-squad-b/q2/

Reorgs every 12–24 months force costly folder moves, ACL rewrites, and asset reprocessing.

→
Refactor /campaigns/2026/<campaign-slug>/

Anchor Level 1 on enduring business domains (/products, /campaigns) that outlast team changes.

Trap 02 · MIME-Type Silos /images/... · /videos/... · /pdfs/...

Splits one campaign across three trees and triples Metadata Profile maintenance.

→
Refactor /campaigns/2026/<slug>/master-toolkit/

Keep mixed campaign formats together; filter by File Type in Omnisearch and Content Advisor.

Trap 03 · Per-Channel Copies /web/hero.jpg + /social/hero.jpg

Creates separate OpenAPI UIDs—version updates or rights expirations miss duplicate copies.

→
Refactor One approved master + OpenAPI URL modifiers

Serve channel sizes from one UID and curate cross-folder kits via Collections.

Trap 04 · Ad-Hoc Folder Sprawl /Johns_Test/ · /New Folder (2)/

Open root creation spawns thousands of folders missing approval schemas and Smart Crops.

→
Refactor Lock Levels 1–2 to dam-administrators

Allow contributor subfolder creation only inside /campaigns/<YYYY>/ and /wip-studio/.

Trap 05 · Blanket Auto-Approval & Crop Bloat 12,000 legacy files dumped with 15+ Smart Crops

Publishes unvetted files to OpenAPI endpoints and throttles ingestion queues.

→
Refactor Partitioned staging + CSV metadata + ~5 crops

Auto-approve only curated brand kits, enrich batch metadata via CSV, and scope lean Image Profiles.
