Bars are illustrative. Adobe’s FAQ says many implementations reach go-live in about 6–9 weeks with parallel work, then a controlled rollout. Hands-on setup ranges from about 3–5 days for a basic implementation to 2–4 weeks for advanced ones; creating the baseline takes about 5 minutes and deployment about 15 minutes of marketer time. The rest is content, integrations, and approvals.

Rule 1Preview is not production

Creating a concierge does not show it to visitors. Deployment is a separate, deliberate step.

Rule 2Involve IT and web early

Their datastream ID and script install are required. Adobe advises bringing them in early.

Rule 3Content sets the ceiling

It answers only from configured knowledge sources, not general web knowledge.

The people

Who is involved

One person may hold several roles. Most hands-on work is marketer self-serve; the other teams supply access, content, IDs, keys, calendars, and approvals.

Leads the work · MKTConcierge owner (marketer)

Configures the concierge in Composer and coordinates every other team. Adobe documents most setup as marketer self-serve.

Core teamsAlways needed · 6 roles

  • ADM
    Organization admin

    Adds users in Adobe Admin Console and creates the Brand Concierge role in Experience Platform Permissions.

  • CNT
    Content owners

    Own the website pages and product data the concierge answers from; review answers.

  • BRD
    Brand team

    Approves brand expression, tone, visual style, and chat components.

  • LGL
    Legal & compliance

    Approves the AI disclosure, guardrails, and consent and privacy handling before go-live.

  • IT
    IT / analytics team

    Provides the datastream ID that receives concierge activity.

  • WEB
    Website team

    Owns the site or tag manager and installs the deployment script. For AEM Sites, provides the Content AI index.

OptionalOnly if you use the feature · 3 roles

  • COM
    Commerce or IT team

    Supplies the Adobe Commerce connection values for Commerce MCP.

  • SLS
    Sales representatives

    Connect their own calendar and set availability for meeting booking and live chat.

  • MKO
    Marketo Engage admin

    Connects Marketo Engage to receive leads and activities.

Stage 1 · PlanSteps 01–02
01

Plan and gather inputs

Agree the scope and line up every input and team before building.

Week 1
Who
Concierge ownerContent ownersIT / analytics teamWebsite team
Where
Your planning workspace—no Adobe tool yet
What to use
Your site analytics and search logs; the website URL; product data; brand guidelines
What to do
  1. Pick one visitor journey to start with, and record today’s baseline for it.Practice
  2. Gather inputs: the website URL (the only required input), product-card data (an AEM Sites / Content AI connection or a product spreadsheet), Adobe Commerce details if relevant, and brand guidelines.
  3. Ask the IT or analytics team for a datastream ID and identify the website team now. Adobe advises involving both early—deployment is not the last-minute step.
  4. Decide between a component on existing pages and a full dedicated page, and list the target domains and page paths.
  5. Decide on optional features: meeting booking, live chat, Marketo Engage.
Done when

Inputs gathered, owners named, page list agreed.

02

Grant access

Give a small, named group the right to build and change the concierge.

Week 1
Who
Organization admin
Where
Adobe Admin Console›Usersexperienceplatform.adobe.com›Permissions›Roles
What to use
The Adobe Experience Platform product profile; a role with Manage Brand Concierge; sandboxes
What to do
  1. In Admin Console, add the user to the organization with the Adobe Experience Platform product profile (default user profile). The invitation alone does not grant Brand Concierge access.
  2. In Experience Platform › Permissions › Roles, select Create a new role, add Manage Brand Concierge, and select only the sandboxes the role needs.
  3. Add users on the role’s Users tab, or select Add Role from a user record.
  4. Keep the role to a few named editors: Manage Brand Concierge is currently the only permission, with no view-only tier.Practice
Done when

Each editor can sign in, open Brand Concierge, and see the granted sandboxes.

Stage 2 · BuildSteps 03–06
03

Create the baseline

Get a working draft in about five minutes, then review what Composer generated.

Week 1–2
Who
Concierge ownerBrand team
Where
Adobe Experience Cloud›Brand Concierge (Composer)
What to use
One-click creation from the website URL; live Preview in desktop and mobile views
What to do
  1. Enter the website URL and select Create.
  2. Review the generated brand expression (formality, warmth, playfulness, energy), then the brand profile (goal, products and services, audience, values, differentiators, use cases).
  3. Review the starting instructions, guardrails, and suggestions, then select Save.
  4. Composer crawls the top 10–15 pages from your sitemap, applies a visual style from your site, and activates the Site Advisory skill with the Knowledge Base Search integration.
  5. Ask representative questions in Preview; select New to restart a conversation.
Done when

The draft answers general questions in Preview. Visitors still see nothing.

04

Prepare the content

Give the concierge complete, current content. It answers only from configured sources.

Weeks 2–4
Who
Content ownersConcierge ownerWebsite team
Where
Composer›Build Knowledge Sourcethen the Knowledge Base Search integration
What to use
AEM Sites (Content AI index) · Website Links (sitemap, URLs, or CSV) · Product Catalog (schema and spreadsheet, about 100 items or fewer)
What to do
  1. Fix gaps and conflicting details on the website first.Practice
  2. Add the full knowledge source. AEM Sites updates automatically; for Website Links, optionally schedule a refresh, such as weekly.
  3. Open the Knowledge Base Search integration and select the knowledge source it should search.
  4. Watch the status. On Partial success, select Fix Issues, correct or remove the URLs, and request reprocessing.
Done when

Every source is fully processed with no unresolved Fix Issues errors.

05

Connect skills and integrations

Decide what the concierge can do, and connect it to the data and people it needs.

Weeks 3–5
Who
Concierge ownerCommerce or IT teamSales representativesMarketo Engage admin
Where
Composer›Browse Skills / Browse IntegrationsExperience Platform›Sales Qualifier
What to use
Skills and their intents; Commerce MCP; Meeting Booking; Live Chat; Managed Members; Simulate
What to do
  1. Turn on the skills the journey needs. For each, set the name, description, and intents (the topics that trigger it), and keep intents distinct so two skills never compete for one question.
  2. Adobe Commerce: enter the environment ID, website code, store code, store view code, and API key from the commerce or IT team in Commerce MCP.
  3. Meeting booking or live chat: each rep opens Sales Qualifier › Profile Settings, connects a calendar, and sets availability. Confirm them under Managed Members, then turn the integration on.
  4. Marketo Engage: connect it to receive leads and activities. This needs Marketo admin access and a feature flag.
  5. Attach integrations to skills (or select Use recommended), save, and select Simulate to test a sample question.
Done when

Each skill fires on its own questions and reaches the right catalog or rep.

06

Set brand rules and compliance

Make it sound like your brand, stay in scope, and meet your legal obligations.

Weeks 3–6
Who
Concierge ownerBrand teamLegal & compliance
Where
Composer›InstructionsTone & VoiceVisual styleChat components
What to use
Instructions, guardrails, and suggestions; tone attributes and response length; welcome message and legal disclaimer text
What to do
  1. Write instructions for trademark usage, response structure, and topics to avoid. Set guardrails—for example, no legal, compliance, or competitor topics.
  2. Decide what happens when it can’t answer: a graceful message, suggested questions, self-service links, or a handoff to a person.
  3. Tune Tone & Voice. For regulated audiences, Adobe suggests moderate enthusiasm and playfulness.
  4. Set visual style and chat components, including source references, ratings, and product cards.
  5. Add an in-conversation AI disclosure: it is generative AI, conversations may be reviewed, and continuing means agreeing.
  6. Have legal and compliance confirm that consent and privacy settings cover chat data and analytics.
Done when

Brand and legal sign-off recorded.

07

Test and evaluate

Show it handles real questions—including the awkward ones—before visitors do.

Weeks 4–7
Who
Concierge ownerContent ownersBrand teamLegal & compliance
Where
Composer›PreviewTester ViewShareRun EvaluationEvaluation Results
What to use
Evaluation sets (golden datasets): functional, out of scope, and safeguard
What to do
  1. Create at least one evaluation set per type—AI-generated from the knowledge source or uploaded as a spreadsheet. Review every question-and-answer pair.
  2. Select Run Evaluation. In Evaluation Results, review the overall score, the high, medium, or low ratings, and the flagged answers.
  3. Test in Preview and Tester View. A thumbs-down opens a form covering response coverage, brand tone, quality, and features.
  4. Share the preview link with reviewers who don’t have Composer access.
  5. Fix content or configuration, then rerun the evaluations.
Done when

Evaluations run for all three types and flagged results addressed.

Stage 4 · LaunchSteps 08–09
08

Deploy to staging

Install the tested concierge where only your team can see it, with activity flowing to Adobe.

Weeks 6–8
Who
Concierge ownerIT / analytics teamWebsite team
Where
Experience Platform›Data Collection›Data Streams (ID only)Composer deployment sectionsite code or tag manager
What to use
Datastream ID; Add Config; component or full-page install; surface rules
What to do
  1. In the deployment section, select Add Config, paste the datastream ID, and save.
  2. Choose Component install (a snippet) or Full-page install (a ready-to-host page), and send it to the website team.
  3. The website team installs it in page code or through a tag manager, like an analytics or chat tag—on a staging or internal-only page first.
  4. Add the staging domain and path rules—any page, starts with, ends with, or exact match—then save.
  5. Verify: the script is on the intended pages; it appears on included pages and not on excluded ones; interactions reach the datastream.
  6. Also check that the disclosure shows and that it works on mobile, with a keyboard, and with a screen reader.Practice
Done when

Staging behaves correctly on included and excluded pages, and activity reaches the datastream.

09

Go live and roll out

Sign off, switch it on for real visitors in production, then ramp from a small share to full traffic.

Weeks 8–9
Who
Concierge ownerWebsite teamIT / analytics teamBrand teamLegal & compliance
Where
Go-live checklistproduction site or tag managerComposer deployment section›surface configurationComposer›Analytics
What to use
Adobe’s go-live checklist; the production script; surface rules; a traffic-split control (tag manager or testing tool); Analytics and transcripts
What to do
  1. Sign off. Complete the go-live checklist and record an owner or evidence for every follow-up. Launch with an open issue only if its owner has reviewed and accepted the risk.
  2. Switch on. The website team adds the script to the production pages, and the concierge owner adds the production domain and paths to the surface rules. The concierge now appears to real visitors on those pages.
  3. Start small. Expose it to about 5% of traffic first.
  4. Control the share outside Composer—a tag manager rule or a testing tool such as Adobe Target traffic allocation—so you can change it without a code release.Practice
  5. Ramp. Scale to 100% over about a week, checking transcripts, ratings, and Analytics before each increase.
  6. Pull back if needed: lower the traffic share, narrow the surface rules, or pause the tag—then fix, rerun evaluations, and ramp again.Practice
  7. Confirm stakeholders can access Analytics.
Done when

100% of intended traffic, no blocking issues, and a named owner for each follow-up.

Stage 5 · RunStep 10
10

Operate and improve

Keep answers accurate as content changes, and show value.

Ongoing
Who
Concierge ownerContent owners
Where
Concierge›Analytics tabView Report (Customer Journey Analytics)Marketo Engage
What to use
Conversations, engaged visitors, positive sentiment, messages per conversation; transcripts; Add to Evaluation
What to do
  1. Review Analytics regularly; Adobe suggests a weekly check-in as a starting point.
  2. Open transcripts and select Add to Evaluation for representative questions, not only negatively rated ones.
  3. Refresh knowledge sources on schedule or manually after site changes, such as pricing or retired pages.
  4. Rerun evaluations after any meaningful change to instructions, guardrails, skills, or integrations.
  5. If sentiment drops, review failed queries, content gaps, and negative feedback, then fix the cause.
  6. Report results against the step 01 baseline, not engagement alone.Practice
Done when

A recurring review is running with named owners.
