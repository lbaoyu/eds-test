Folder Guidance

Four refinements to make the structure scale

Each adjustment below solves a real operational bottleneck once teams start uploading campaigns, delivering images via Dynamic Media, and adapting designs in Adobe Express.

Refinement 01 · File Formats High Impact

Merge Video into domain folders & broaden Photography

Splitting Level 2 by file format scatters a single campaign’s assets across two trees and duplicates folder tagging. Keep campaign and product videos inside their matching Campaign or Product folder—AEM Search and Adobe Express filter by format in one click. Rename Photography to shared-media/ for reusable evergreen lifestyle, executive portraits, and licensed stock.

> Photography / > Video → shared-media/ + format filter
Refinement 02 · Campaigns Automation Win

Nest Campaign Name under Year (move Type to metadata)

Campaign Type (Acquisition, Retention, Seasonal) works best as a search filter, whereas grouping all campaigns of one type together quickly breaches the 1,000-file folder ceiling. Using campaigns / 2026 / <campaign-name>/ keeps folders lean and lets a folder Metadata Profile auto-stamp both Year and Campaign Name on upload.

campaigns / 2026 / <type> → campaigns / 2026 / <campaign>
Refinement 03 · Lifecycle Governance Gate

Separate approved masters, Express saves & studio WIP

Without a dedicated save-back zone, marketers save unreviewed Adobe Express exports straight into master folders. Split each campaign into read-only master-toolkit/ (approved building blocks + Dynamic Media Smart Crops) and express-adaptations/ (lands unapproved for review), plus add BU-level wip-studio/ for raw agency drafts and an Admin-only /archive/.

Single flat campaign folder → master-toolkit/ + express-adaptations/
Refinement 04 · Brand & Templates Express Clarity

Standardize Brand Foundation & clarify Templates

Housing logos, icons, and guidelines in brand-foundation/ under each BU (plus enterprise marks under amp-enterprise/) lets Brand Managers auto-approve official identity kits while keeping them read-only for marketers. Use DAM templates/ for downloadable .pptx / .dotx / .indd files—live Adobe Express templates belong in Express Brands & Libraries.

Ambiguous > Templates → DAM docs vs. Express Brand Libraries

Metadata Review

How your 7 proposed fields pair with folder automation

Your proposed metadata list is lean and practical. The key to high user adoption is auto-stamping predictable fields via Folder Metadata Profiles so uploaders only fill in 2–3 controlled dropdowns—plus adding three high-value fields highlighted below.

Metadata Field Review Status How to Populate Guidance for AMP
Campaign Name Keep Auto-stamped by <campaign>/ folder profile Saves authors from typing campaign names manually on every upload and powers cross-BU Search & Express filters.
Year Keep Auto-stamped by 2026/ folder profile Auto-fill on campaign folders; leave optional on evergreen Brand and Product assets that span multiple years.
Audience Keep Controlled multi-select dropdown / tag Use standardized values (e.g., Advisers, Retail Members, Homebuyers, Brokers, Internal)—never free text.
Channel Keep Controlled multi-select dropdown / tag Replaces channel folders so a single approved image can serve Web, Social, Email, and Adviser Portals at once.
Asset Type Refine Meaning Controlled single-select dropdown Define as Business Asset Type (Key Visual, Packshot, Logo, Fact Sheet, Executive Bio)—AEM already extracts technical file formats (JPG, MP4, PDF) automatically.
Status Keep (Critical) System Review Status field Directly gates Dynamic Media (OpenAPI) delivery and surfaces approved renditions inside Adobe Express. Restrict edit rights on this field to designated Approvers.
Usage Rights Keep Dropdown + mandatory on shared-media/ Capture license scope (e.g., Owned Perpetual, Licensed Paid Stock, Talent Restricted) so Express users know where an image is cleared to run.
+ Expiration Date Add (Essential) System Expiration Date picker Pair with Usage Rights: when an asset passes its Expiration Date, AEM flags it and Dynamic Media automatically stops serving it.
+ Business Unit Add (Auto) Auto-stamped at L1 BU root folder Zero effort for users—stamps North, Bank, Super, Foundation, or AMP Enterprise automatically so global search can filter by BU.
+ Campaign Type Move from Folder Controlled dropdown on Campaign schema Moved out of the folder path so marketers can slice campaigns by Acquisition, Retention, Brand, Regulatory, or Event in Search without deep folders.
