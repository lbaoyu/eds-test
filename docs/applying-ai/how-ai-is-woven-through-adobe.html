How AI is woven through Adobe

Six building blocks — model, tool, agent, connector, skill, plugin — are the method; Adobe’s AI is the subject. It runs across Creative Cloud, Document Cloud, Experience Cloud, and Commerce, and it isn’t one thing: it spans predictive and generative, assistant and agent — from a single generative fill to a governed, multi-step campaign.

  • Six layers, one stack
  • Four modes: predictive · generative · assistant · agentic
  • Lifecycle: plan → create → activate → measure → optimize

The mental model

Six layers, one stack

The vocabulary gets listed side by side, as if you pick one. You don’t. A model sits at the bottom; everything above gives it hands, knowledge, reach, or packaging. Read it bottom-up — then, in the sections that follow, watch the same six layers reappear right across Adobe’s portfolio.

PACKAGEPluginBundles the layers below into one installable unit
KNOW-HOWSkillOn-demand instructions — how to do a task well
REACHConnectorA governed pipe to outside data and tools (MCP)
LOOPAgentThe model calling tools in a loop toward a goal
ACTIONToolOne callable function the model can invoke
BRAINModelThe intelligence itself — generative or predictive

Dependency runs upward — each layer builds on the one beneath it. Connectors and skills feed the agent from the side; a plugin reaches down and wraps whichever ship together. Throughout, a Beta or Preview tag marks capabilities that aren’t generally available — check the customer’s entitlement before promising them.

How to read it

Four modes, plus AI-first

Before the layers, the distinction that prevents most confusion: Adobe’s AI isn’t a single kind of thing. The same six-layer stack shows up in four modes — and a fifth pattern, the AI-first application, where the whole product is built around them.

ModeWhat it doesAdobe examples
PredictiveFinds patterns, scores, ranks, recommendsSensei smart tagging & cropping, propensity/churn scores, Commerce Live Search & recommendations
GenerativeCreates or transforms contentFirefly generation, Photoshop Generative Fill, Illustrator Text to Vector, AEM Generate Variations
AssistantConverses: learn, search, summarize, sometimes actAcrobat AI Assistant; AI Assistant in Experience Platform, AEM, Workfront, Marketo, Express
AgenticPlans, calls tools, checks, drives to an outcomeCX Enterprise Coworker; Audience, Journey & Experimentation Agents; Brand Concierge; Marketo AI

The fifth pattern — the AI-first application, designed around intent rather than adding AI as a button — covers GenStudio for Performance Marketing, Brand Concierge, AEM Sites Optimizer, and the Firefly app.

The distinction to keep

Predictive finds, generative makes, assistants converse, agents act. Naming the mode first settles the “but is it really an agent?” argument before it starts.

The base

The model: raw intelligence

The model is the intelligence that interprets inputs or generates outputs. On the text side these are the familiar frontier LLMs — GPT-5, Claude, Gemini — but Adobe’s model layer is broader than any one of them, and broader than generative alone.

Adobe example

Firefly is Adobe’s family of creative models — image, video, audio, vector, text effects — and, in many surfaces, a model-selection layer where Adobe’s own models sit alongside selected partner models, with Adobe managing the available choices, capabilities, and credits.

Sensei is the other half of the model layer: machine-learning models that classify, rank, and predict — smart tagging, propensity scoring, search ranking. And the conversational assistants ride on a mix of Adobe technology and external LLMs wrapped in product knowledge, permissions, and governance — which is why two products on a similar base model can feel completely different.

Layer one · action

Tools: giving the model hands

A tool is a single callable function the model can invoke. The mechanism has a name — function calling, or tool use: the model emits a structured request, code runs it, the result returns. Adobe has turned a great many app functions into AI-callable actions.

Adobe example

Creative: Generate Image, Generative Fill, Remove Background, Text to Vector Graphic, Generative Extend in Premiere, Generate Sound Effects. Document: Acrobat’s chat can summarize a PDF, compare files, reorganize pages, add a watermark, or build a presentation from the content. Marketing & work: create or refine an audience, generate a Workfront formula, validate a Marketo program, spin content variations for email or ads.

The design shift is the point: you describe the outcome, and the assistant selects the tool or tools — you no longer have to find the right menu.

Layer two · the loop

Agents: from answers to outcomes

An assistant helps with a question or a single task. An agent goes further: it understands a goal, retrieves context, plans, selects tools or specialist agents, executes multiple steps, checks results, asks for approval when needed, and continues. Autonomy across steps is the dividing line — and “agent” is badly overloaded, so the useful test is whether it plans and acts across steps without a human in each one.

In the broad market you’ll know these as coding agents — Claude Code, GitHub Copilot, Devin. In Adobe, agents show up across the Experience Cloud, coordinated by Experience Platform Agent Orchestrator (the reasoning layer — not itself a domain agent):

AgentWhat it does
Audience AgentExplore and refine audiences, size them, spot duplicates and significant changes
Journey AgentBuild journeys from a description, find drop-off, detect conflicts, recommend fixes
Data Insights AgentAsk questions of profile and event data, build visualizations, surface trends
Experimentation AgentReview tests, predict impact, find gaps, propose and prioritize experiments
Product Support AgentTroubleshoot Experience Cloud with product knowledge and diagnostics
AEM agentsBrand Experience, Content Advisor, Governance — create, analyze, and govern content
Marketo AIImport, normalize, and dedupe leads; validate programs; investigate lead flow

Above the individual agents sits Adobe CX Enterprise Coworker, the agentic orchestration layer for customer-experience work. It is the step past an assistant: where AI Assistant answered questions and launched purpose-built agents, Coworker takes an outcome-level goal, selects the right skills and agents, invokes tools across Adobe and connected systems, validates the result, and returns finished work for human approval. Coworker Chat is its conversational interface; Coworker Campaigns packages campaign creation and execution, and Coworker Projects Preview extends the same foundation into ongoing cross-team workflows.

One product family, two layers: Coworker is the agent; its CX Coworker Gateway is the connector that opens those same capabilities to outside clients — see the next section.

Adobe example

Brand Concierge is the multi-agent app they power: Orchestrator routes each conversation to the right specialist — the Product Advisor Agent for B2C discovery, the Account Qualification Agent for B2B buyers. The Marketing Agent for Microsoft 365 Copilot pulls Experience Platform insights into Teams, Word, and Excel without switching apps.

Why it matters

Because frontier models have converged, the agent — the harness that plans, remembers, and recovers from errors — increasingly decides the experience more than the model inside it. Pick the harness for the job, not just the smartest model.

Layer one · reach

Connectors: reaching Adobe systems safely

A connector wires the model to an external system — data and tools it has no native access to. The fragmented, bespoke-integration era (an N×M problem) gave way to a standard: the Model Context Protocol (MCP), “USB-C for AI,” collapsing N×M to N+M. It went vendor-neutral fast — OpenAI, Google, and Microsoft adopted it, and it now sits under the Linux Foundation.

Adobe example

Adobe exposes governed capability through MCP. The AEM MCP servers cover content work across distinct surfaces — Content, Cloud Manager, Experience Governance, Content AI. The Workfront MCP Server lets an AI client find, create, and update work items in natural language. The CX Coworker Gateway is the connector-side counterpart to Coworker itself — a unified, governed MCP endpoint exposing the Experience Cloud capabilities an organization is entitled to, to external clients like Claude, ChatGPT, and Cursor. And “Adobe for creativity” is a single aggregator endpoint fanning out to Photoshop, Firefly, Express, and more.

The line that makes “reach” precise: connectors run under your own Adobe permissions. If you can’t edit a fragment in AEM by hand, you can’t through MCP either — reach, not privilege.

Layer two · know-how

Skills: teaching AI how the work is done

A skill is packaged instructions — how to do a kind of task well — loaded only when relevant. It grants no new access; it’s procedure the model reads and follows. The rule of thumb worth memorizing: skills teach, connectors reach.

Adobe example

In Adobe, skills are the procedural knowledge that keeps output correct: brand voice, tone, and logo rules in GenStudio brand guidelines; AEM Agent Skills and an AGENTS.md that tell a coding agent how your project works; Marketo validation rules; approval and localization procedures; prompt libraries.

Adobe Brand Intelligence even uses the word literally — a headless brand layer whose capabilities are named Validate, Assemble, Predict, and Instruct to Generate, which agents draw on during content creation. None of these grant new system access; they shape how the work is done.

In practice the layers cooperate: a brand skill says “use approved language,” a connector reads and updates the content, a tool produces the variation, and an approval gate puts a human in the loop before it publishes.

Layer three · packaging

Plugins & wrappers: Adobe inside other tools

A plugin bundles some mix of tools, connectors, skills, and commands into one installable unit — the packaging layer, not a new capability. The word hit the mainstream with ChatGPT Plugins (2023), later folded into GPTs and largely superseded by MCP-based apps.

Adobe example

The Adobe plugin in ChatGPT is the headline — one installable extension, invoked with @Adobe, bundling dozens of tools (70-plus at launch) across Photoshop, Firefly, Acrobat, Express, Premiere, Lightroom, Illustrator, InDesign, and Stock. It began as three separate “apps for ChatGPT” (Photoshop, Express, Acrobat) and consolidated into one.

The wrapping runs both ways: AI Assistant embedded inside Adobe apps, and the CX Coworker Gateway exposing Experience Cloud outward to external clients.

The whole stack in one product

That plugin is every layer at once: Firefly and its partner models (the model), dozens of callable actions (tools), MCP wiring underneath (the connector), your brand assets and saved Creative Cloud files (skill + memory), running inside ChatGPT (the agent surface) and shipped as one @Adobe bundle (the plugin).

The bigger picture

AI across the content lifecycle

Step back from the layers and the pattern is a lifecycle. Adobe places AI at every stage, and the value compounds when the stages are connected — the content-supply-chain argument.

01 Plan

Workfront — AI Assistant, MCP Server

02 Create

Firefly, Photoshop, Illustrator, Express, InDesign, Premiere; GenStudio

03 Manage

AEM Sites, Assets, Content Hub; smart tagging; Content AI

04 Activate

Journey Optimizer, Marketo, Commerce

05 Measure

Customer Journey Analytics, Content Analytics, experimentation

06 Optimize

Agents propose the next variation, audience, or test

Two tracks run alongside this loop. Document Cloud turns static PDFs into an interactive knowledge source — Acrobat AI Assistant answers, summarizes, compares, and reorganizes. And in Commerce, AI drives discovery (Live Search, faceting, recommendations) and product-catalog enrichment Beta — which points at a newer discipline: where SEO helps pages rank in search engines, AI-visibility optimization (Adobe Brand Visibility, LLM Optimizer) helps content be understood and recommended by AI systems.

How the layers combine

One goal, every layer

An illustrative end-to-end run — “Create and launch a personalized spring campaign for high-value customers, using approved brand assets, then optimize on performance” — touches all six layers and both modes:

  1. Intent

    The user states the business goal in natural language, via an AI Assistant or an external AI client.

  2. Context

    The system pulls profiles (Experience Platform), audiences (Real-Time CDP), approved assets and brand rules (AEM), and prior performance.

  3. Plan

    Agent Orchestrator decides which specialist agents and tools the task needs.

  4. Generate

    Firefly and GenStudio produce on-brand image, copy, and channel variations.

  5. Govern

    Skills and guardrails check brand voice, permissions, disclaimers, and required approvals.

  6. Activate

    Journey Optimizer, Marketo, or Commerce delivers the selected content to the right audience and channel.

  7. Measure & optimize

    Customer Journey Analytics and experimentation evaluate results; the agent proposes the next variation, audience, or test.

intent → context → plan → agents → tools → governance → activation → measurement → optimization

Across every layer

Governance isn’t a layer — it’s a lens

Responsible AI cuts across the whole stack rather than sitting on top of it. The pieces worth naming in any field conversation:

Provenance

Content Credentials record how content was made or edited; Firefly output can carry a credential noting generative AI.

Training data

Adobe states the initial commercial Firefly model trained on Adobe Stock, licensed, and public-domain content, and not on subscribers’ personal work. Treat as a product-specific commitment, not a blanket rule.

Permissions

MCP connectors and Experience Platform agents honor existing product access — no privilege escalation through an AI client.

Human oversight

Agentic work can require confirmation before irreversible actions, approval gates, review queues, and audit trails.

Usage & entitlement

Adobe separates generative credits from Experience Platform AI credits; availability varies by plan, region, role, and rollout stage.

The rest of the vocabulary

Words you’ll hear in the same breath

Predictive vs generative
Predictive AI (Sensei) finds patterns and scores likelihoods; generative AI (Firefly) creates content. Different jobs, often in the same product.
Assistant vs agent
An assistant helps you with a step; an agent plans and executes several toward a goal. The gap is autonomy, not intelligence.
RAG
Retrieval-augmented generation — fetch relevant content into context before answering. Adobe: how Brand Concierge grounds answers in first-party data and approved content.
Fine-tuning
Adjusting a model’s weights on your data — it changes the model itself. Adobe: Firefly Custom Models, trained on your own images for a consistent style.
Orchestration
The layer that routes work between models, tools, and agents. Adobe named its version literally: AEP Agent Orchestrator.
Guardrails
The validation layer constraining what a model or agent may do or say. Adobe: GenStudio brand scoring and Brand Intelligence checks.
Content Credentials
Tamper-evident provenance metadata attached to an asset, recording tools and AI used. Adobe co-founded the standard behind it.
Workflow vs agent
A workflow runs fixed, predefined steps; an agent chooses its own. Adobe: Firefly’s Workflow Builder runs set steps; an Orchestrator agent decides them.

The takeaway

One line per layer

  • Model — the intelligence, generative or predictive. Adobe: Firefly & Sensei
  • Tool — a single action it can take. Adobe: Generative Fill, Acrobat actions, audience queries
  • Agent — the model in a loop toward a goal. Adobe: CX Coworker, Agent Orchestrator, Brand Concierge
  • Connector (MCP) — governed reach to data and tools; reach. Adobe: AEM & Workfront MCP, CX Coworker Gateway
  • Skill — on-demand instructions; teaching. Adobe: brand guidelines, AEM Agent Skills, AGENTS.md
  • Plugin — the box that bundles the above. Adobe: the @Adobe plugin in ChatGPT
The thesis

Adobe is weaving AI into the entire lifecycle of content and experiences — plan, create, manage, activate, measure, optimize — in four modes and six layers. Skills teach, connectors reach, agents act; when a pitch blurs them, ask which layer and which mode it means.
